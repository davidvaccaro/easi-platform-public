Pipeline Selection

Selection terminals provide targeted extraction of DICOM® attributes and values without requiring full native object materialization when only a constrained subset is needed.

Purpose

Use selection when workloads need specific tags or value paths for indexing, routing, analytics, or pre-flight validation. Selection is often the lowest-cost semantic terminal for metadata-first workflows.

Normative Requirement

Selection implementations MUST expose deterministic completion semantics and MUST preserve parser lifecycle event ordering when deciding early completion or partial extraction.

Builder Surface

Builder Surface Description
toSelection(selection) Bind one custom selection implementation.
EASI.selectionBuilder() Compose tag/criteria extraction contracts using the staged selection builder.
process(source) Late-bind source and receive one PipelineResultCollection with selection output.

Usage

Selection terminals return one PipelineResultCollection per transaction. The first() item is an AttributeSet containing only the selected attributes.

Language-Neutral Examples

selection := EASI.selectionBuilder()
  .include([
    Tag.StudyInstanceUID,
    Tag.SeriesInstanceUID,
    Tag.SOPInstanceUID,
    Tag.Modality
  ])
  .build()

pipeline := EASI.pipelineBuilder()
  .fromFileStream()
  .ofDicomData()
  .toSelection(selection)
  .build()

resultCollection := pipeline.process(sourcePath)
if resultCollection.isEmpty:
  fail("Expected one selection result")
selectionResult := resultCollection.first()

studyUid := selectionResult.value(Tag.StudyInstanceUID)
seriesUid := selectionResult.value(Tag.SeriesInstanceUID)
sopUid := selectionResult.value(Tag.SOPInstanceUID)
modality := selectionResult.value(Tag.Modality)

Selection Design Notes

  • Prefer explicit tag contracts over broad wildcard extraction.
  • Define behavior for missing, empty, and repeated values.
  • If early completion is supported, document the stop condition clearly.
  • Keep output shape stable so downstream integrations remain deterministic.
