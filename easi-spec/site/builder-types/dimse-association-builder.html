DimseAssociationBuilder

Builds validated DIMSE association descriptors, including endpoint identity, query options, TLS, move-store behavior, and timeout policy.

Builder Identity

Field Value
Builder Type DimseAssociationBuilder
Primary Purpose Builds validated DIMSE association descriptors, including endpoint identity, query options, TLS, move-store behavior, and timeout policy.
Build Output DIMSE association options object
Factory Entry Point `EASI.dimseAssociationBuilder()`

Usage Examples

The following examples demonstrate language-neutral semantics and language-specific usage forms.

Create a Basic DIMSE Association

Define the minimum host/port/AE-title descriptor for query/retrieve transport.

association := EASI.dimseAssociationBuilder()
  .withHost("127.0.0.1")
  .withPort(4242)
  .withCallingAeTitle("EASI_JS")
  .withCalledAeTitle("ORTHANC")
  .build()
const association = EASI.dimseAssociationBuilder()
  .withHost("127.0.0.1")
  .withPort(4242)
  .withCallingAeTitle("EASI_JS")
  .withCalledAeTitle("ORTHANC")
  .build();
var association = EASI.DimseAssociationBuilder()
    .WithHost("127.0.0.1")
    .WithPort(4242)
    .WithCallingAeTitle("EASI_JS")
    .WithCalledAeTitle("ORTHANC")
    .Build();
var association = EASI.dimseAssociationBuilder()
    .withHost("127.0.0.1")
    .withPort(4242)
    .withCallingAeTitle("EASI_JS")
    .withCalledAeTitle("ORTHANC")
    .build();
association = (
    EASI.dimse_association_builder()
    .with_host("127.0.0.1")
    .with_port(4242)
    .with_calling_ae_title("EASI_JS")
    .with_called_ae_title("ORTHANC")
    .build()
)
Configure Query, TLS, and Move-Store Policy

Add DIMSE query options, outbound TLS, move-store policy, and timeout controls.

association := EASI.dimseAssociationBuilder()
  .withBaseAssociation(baseAssociation)
  .withQueryOption("operation", "cmove")
  .withMoveDestinationAeTitle("EASI_DEST")
  .withTransportTls({ rejectUnauthorized: true, servername: "pacs.local" })
  .withMoveStorePolicyOption("associationTimeoutMs", 45000)
  .withAssociationTimeoutMs(30000)
  .build()
const association = EASI.dimseAssociationBuilder()
  .withBaseAssociation(baseAssociation)
  .withQueryOption("operation", "cmove")
  .withMoveDestinationAeTitle("EASI_DEST")
  .withTransportTls({ rejectUnauthorized: true, servername: "pacs.local" })
  .withMoveStorePolicyOption("associationTimeoutMs", 45000)
  .withAssociationTimeoutMs(30000)
  .build();
var association = EASI.DimseAssociationBuilder()
    .WithBaseAssociation(baseAssociation)
    .WithQueryOption("operation", "cmove")
    .WithMoveDestinationAeTitle("EASI_DEST")
    .WithTransportTls(new { rejectUnauthorized = true, servername = "pacs.local" })
    .WithMoveStorePolicyOption("associationTimeoutMs", 45000)
    .WithAssociationTimeoutMs(30000)
    .Build();
var association = EASI.dimseAssociationBuilder()
    .withBaseAssociation(baseAssociation)
    .withQueryOption("operation", "cmove")
    .withMoveDestinationAeTitle("EASI_DEST")
    .withTransportTls(Map.of("rejectUnauthorized", true, "servername", "pacs.local"))
    .withMoveStorePolicyOption("associationTimeoutMs", 45000)
    .withAssociationTimeoutMs(30000)
    .build();
association = (
    EASI.dimse_association_builder()
    .with_base_association(base_association)
    .with_query_option("operation", "cmove")
    .with_move_destination_ae_title("EASI_DEST")
    .with_transport_tls({"rejectUnauthorized": True, "servername": "pacs.local"})
    .with_move_store_policy_option("associationTimeoutMs", 45000)
    .with_association_timeout_ms(30000)
    .build()
)
