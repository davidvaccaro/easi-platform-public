DicomDeIdentificationMaskBuilder

Builds de-identification mask maps used by `withDeIdentification(...)` filters, including defaults, merges, direct set/remove operations, and tag resolution helpers.

Primary Purpose Builds de-identification mask maps used by `withDeIdentification(...)` filters, including defaults, merges, direct set/remove operations, and tag resolution helpers.
Build Output De-identification mask map (`Map<string, { ID, Action }>`)
Factory Entry Point `EASI.deIdentificationMaskBuilder()`

Usage Examples

The following examples demonstrate language-neutral semantics and language-specific usage forms.

Default Profile with Explicit Overrides

Start from the standard mask profile and override specific tag behaviors.

mask := EASI.deIdentificationMaskBuilder()
  .withDefaultProfile()
  .set("PatientID", "[REMOVED]")
  .set("AccessionNumber", "[MASKED]")
  .build()
const mask = EASI.deIdentificationMaskBuilder()
  .withDefaultProfile()
  .set("PatientID", "[REMOVED]")
  .set("AccessionNumber", "[MASKED]")
  .build();
var mask = EASI.DeIdentificationMaskBuilder()
    .WithDefaultProfile()
    .Set("PatientID", "[REMOVED]")
    .Set("AccessionNumber", "[MASKED]")
    .Build();
var mask = EASI.deIdentificationMaskBuilder()
    .withDefaultProfile()
    .set("PatientID", "[REMOVED]")
    .set("AccessionNumber", "[MASKED]")
    .build();
mask = (
    EASI.de_identification_mask_builder()
    .with_default_profile()
    .set("PatientID", "[REMOVED]")
    .set("AccessionNumber", "[MASKED]")
    .build()
)
