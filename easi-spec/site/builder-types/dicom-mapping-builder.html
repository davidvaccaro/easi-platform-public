DicomMappingBuilder

Builds DICOM tag-to-domain mapping definitions for `toMapping(...)` terminals, including direct mappings, template properties, and computed expressions.

Builder Identity

Field Value
Builder Type DicomMappingBuilder
Primary Purpose Builds DICOM tag-to-domain mapping definitions for `toMapping(...)` terminals, including direct mappings, template properties, and computed expressions.
Build Output DicomMapping
Factory Entry Point `EASI.mappingBuilder()`

Usage Examples

The following examples demonstrate language-neutral semantics and language-specific usage forms.

Direct Tag Mapping with Properties

Map key DICOM attributes to an application model and include template properties.

mapping := EASI.mappingBuilder()
  .withTemplatePolicy("omit")
  .withProperty("sourceSystem", "pacs-a")
  .map("StudyInstanceUID", "study.uid")
  .map("SeriesInstanceUID", "series.uid")
  .build()
const mapping = EASI.mappingBuilder()
  .withTemplatePolicy("omit")
  .withProperty("sourceSystem", "pacs-a")
  .map("StudyInstanceUID", "study.uid")
  .map("SeriesInstanceUID", "series.uid")
  .build();
var mapping = EASI.MappingBuilder()
    .WithTemplatePolicy("omit")
    .WithProperty("sourceSystem", "pacs-a")
    .Map("StudyInstanceUID", "study.uid")
    .Map("SeriesInstanceUID", "series.uid")
    .Build();
var mapping = EASI.mappingBuilder()
    .withTemplatePolicy("omit")
    .withProperty("sourceSystem", "pacs-a")
    .map("StudyInstanceUID", "study.uid")
    .map("SeriesInstanceUID", "series.uid")
    .build();
mapping = (
    EASI.mapping_builder()
    .with_template_policy("omit")
    .with_property("sourceSystem", "pacs-a")
    .map("StudyInstanceUID", "study.uid")
    .map("SeriesInstanceUID", "series.uid")
    .build()
)
Fluent `map(...).to(...)` + Computed Rule

Use two-step mapping syntax and computed values for derived properties.

mapping := EASI.mappingBuilder()
  .map("PatientID").to("patient.identifier")
  .withComputed("study.isLongitudinal", {
    from: ["StudyDate", "StudyTime"],
    expression: "hasPriorExam == true"
  })
  .build()
const mapping = EASI.mappingBuilder()
  .map("PatientID").to("patient.identifier")
  .withComputed("study.isLongitudinal", {
    from: ["StudyDate", "StudyTime"],
    expression: "hasPriorExam == true"
  })
  .build();
var mapping = EASI.MappingBuilder()
    .Map("PatientID").To("patient.identifier")
    .WithComputed("study.isLongitudinal", new {
        from = new[] { "StudyDate", "StudyTime" },
        expression = "hasPriorExam == true"
    })
    .Build();
var mapping = EASI.mappingBuilder()
    .map("PatientID").to("patient.identifier")
    .withComputed("study.isLongitudinal", Map.of(
        "from", java.util.List.of("StudyDate", "StudyTime"),
        "expression", "hasPriorExam == true"
    ))
    .build();
mapping = (
    EASI.mapping_builder()
    .map("PatientID").to("patient.identifier")
    .with_computed("study.isLongitudinal", {
        "from": ["StudyDate", "StudyTime"],
        "expression": "hasPriorExam == true"
    })
    .build()
)
