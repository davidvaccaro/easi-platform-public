PipelineBuilder

Defines staged, fluent composition of complete EASI pipelines from source acquisition through parsing, policy/filter application, terminal materialization, optional writer delivery, and final build.

Builder Identity

Field Value
Builder Type PipelineBuilder
Primary Purpose Defines staged, fluent composition of complete EASI pipelines from source acquisition through parsing, policy/filter application, terminal materialization, optional writer delivery, and final build.
Build Output Pipeline
Factory Entry Point `EASI.pipelineBuilder()`

Usage Examples

The following examples demonstrate language-neutral semantics and language-specific usage forms.

Read One DICOM Instance

Build a minimal pipeline that reads one DICOM source and returns typed instance output.

sourceUrl := "https://pacs.example.org/dicom-web/studies/{studyUID}/series/{seriesUID}/instances/{instanceUID}"

pipeline := EASI.pipelineBuilder()
  .fromHttpStream()
  .ofDicomData()
  .toInstances()
  .build()

results := pipeline.process(sourceUrl)
instance := results.first()

  .build();

DIMSE Source, De-ID, and HTTP Relay

Compose a multi-stage workflow that listens to DIMSE input, applies in-flight policy, and relays to HTTP output.

pipeline := EASI.pipelineBuilder()
  .fromDimseAssociation(sourceAssociation)
  .ofDicomData()
  .withDeIdentification(Tag.DefaultDeIdentificationMask)
  .toDicomData()
  .intoHttpStream("https://cloud.example.org/dicom-web/studies", {
    method: "POST",
    stow: true
  })
  .build()

run := pipeline.start()
run.stop()
const pipeline = EASI.pipelineBuilder()
  .fromDimseAssociation(sourceAssociation)
  .ofDicomData()
  .withDeIdentification(Tag.DefaultDeIdentificationMask)
  .toDicomData()
  .intoHttpStream("https://cloud.example.org/dicom-web/studies", {
    method: "POST",
    stow: true
  })
  .build();

const run = await pipeline.start();
await run.stop();
var pipeline = EASI.PipelineBuilder()
    .FromDimseAssociation(sourceAssociation)
    .OfDicomData()
    .WithDeIdentification(Tag.DefaultDeIdentificationMask)
    .ToDicomData()
    .IntoHttpStream("https://cloud.example.org/dicom-web/studies", new {
        method = "POST",
        stow = true
    })
    .Build();

var run = await pipeline.Start();
await run.Stop();
var pipeline = EASI.pipelineBuilder()
    .fromDimseAssociation(sourceAssociation)
    .ofDicomData()
    .withDeIdentification(Tag.DefaultDeIdentificationMask)
    .toDicomData()
    .intoHttpStream("https://cloud.example.org/dicom-web/studies", Map.of(
        "method", "POST",
        "stow", true
    ))
    .build();

var run = pipeline.start();
run.stop();
pipeline = (
    EASI.pipeline_builder()
    .from_dimse_association(source_association)
    .of_dicom_data()
    .with_de_identification(Tag.default_de_identification_mask)
    .to_dicom_data()
    .into_http_stream("https://cloud.example.org/dicom-web/studies", {
        "method": "POST",
        "stow": True
    })
    .build()
)

run = pipeline.start()
run.stop()
