DimseClientBuilder

Creates DIMSE client instances for association-level operations (for example C-ECHO) with explicit association and transport configuration.

Builder Identity

Field Value
Builder Type DimseClientBuilder
Primary Purpose Creates DIMSE client instances for association-level operations (for example C-ECHO) with explicit association and transport configuration.
Build Output DimseClient
Factory Entry Point `EASI.dimseClientBuilder()`

Builder API Method Summary

Exposed methods for DimseClientBuilder in this stage/group.

Method Signature Returns Purpose
withAssociation withAssociation(association = null) DimseClientBuilder Configure the default association object for the DIMSE client.
withAssociationBuilder withAssociationBuilder(associationBuilder) DimseClientBuilder Configure the association via one association builder object.
withTransport withTransport(transport = null) DimseClientBuilder Configure one DIMSE client transport. Transport should implement `echo(association, options)`.
build build() DimseClient Build one DIMSE client from configured builder state.

Usage Examples

The following examples demonstrate language-neutral semantics and language-specific usage forms.

Build a Client and Run C-ECHO

Use a built association object and default transport to create a client and issue an echo.

client := EASI.dimseClientBuilder()
  .withAssociation(association)
  .build()

echoResult := client.echo()
const client = EASI.dimseClientBuilder()
  .withAssociation(association)
  .build();

const echoResult = await client.echo();
var client = EASI.DimseClientBuilder()
    .WithAssociation(association)
    .Build();

var echoResult = await client.Echo();
var client = EASI.dimseClientBuilder()
    .withAssociation(association)
    .build();

var echoResult = client.echo();
client = (
    EASI.dimse_client_builder()
    .with_association(association)
    .build()
)

echo_result = client.echo()
Compose Association with Builder + Custom Transport

Chain association builder composition into client builder and override the DIMSE transport implementation.

client := EASI.dimseClientBuilder()
  .withAssociationBuilder(
    EASI.dimseAssociationBuilder()
      .withHost("127.0.0.1")
      .withPort(4242)
      .withCallingAeTitle("EASI_JS")
      .withCalledAeTitle("ORTHANC")
  )
  .withTransport(customDimseTransport)
  .build()
const client = EASI.dimseClientBuilder()
  .withAssociationBuilder(
    EASI.dimseAssociationBuilder()
      .withHost("127.0.0.1")
      .withPort(4242)
      .withCallingAeTitle("EASI_JS")
      .withCalledAeTitle("ORTHANC")
  )
  .withTransport(customDimseTransport)
  .build();
var client = EASI.DimseClientBuilder()
    .WithAssociationBuilder(
        EASI.DimseAssociationBuilder()
            .WithHost("127.0.0.1")
            .WithPort(4242)
            .WithCallingAeTitle("EASI_JS")
            .WithCalledAeTitle("ORTHANC")
    )
    .WithTransport(customDimseTransport)
    .Build();
var client = EASI.dimseClientBuilder()
    .withAssociationBuilder(
        EASI.dimseAssociationBuilder()
            .withHost("127.0.0.1")
            .withPort(4242)
            .withCallingAeTitle("EASI_JS")
            .withCalledAeTitle("ORTHANC")
    )
    .withTransport(customDimseTransport)
    .build();
client = (
    EASI.dimse_client_builder()
    .with_association_builder(
        EASI.dimse_association_builder()
        .with_host("127.0.0.1")
        .with_port(4242)
        .with_calling_ae_title("EASI_JS")
        .with_called_ae_title("ORTHANC")
    )
    .with_transport(custom_dimse_transport)
    .build()
)
