CodecRegistryBuilder

Composes and validates codec registry instances used by codec-aware handlers (asset extraction, transcoding, and image workflows).

Builder Identity

Field Value
Builder Type CodecRegistryBuilder
Primary Purpose Composes and validates codec registry instances used by codec-aware handlers (asset extraction, transcoding, and image workflows).
Build Output CodecRegistry
Factory Entry Point `EASI.codecRegistryBuilder()`

Usage Examples

The following examples demonstrate language-neutral semantics and language-specific usage forms.

Seed with Defaults and Add Custom Decoder

Start from default codecs and register one custom transfer-syntax decoder.

codecRegistry := EASI.codecRegistryBuilder()
  .withDefaultCodecs(true)
  .withDecoderForTransferSyntax("1.2.840.10008.1.2.4.90", Jpeg2000Decoder)
  .build()
const codecRegistry = EASI.codecRegistryBuilder()
  .withDefaultCodecs(true)
  .withDecoderForTransferSyntax("1.2.840.10008.1.2.4.90", Jpeg2000Decoder)
  .build();
var codecRegistry = EASI.CodecRegistryBuilder()
    .WithDefaultCodecs(true)
    .WithDecoderForTransferSyntax("1.2.840.10008.1.2.4.90", Jpeg2000Decoder)
    .Build();
var codecRegistry = EASI.codecRegistryBuilder()
    .withDefaultCodecs(true)
    .withDecoderForTransferSyntax("1.2.840.10008.1.2.4.90", Jpeg2000Decoder.class)
    .build();
codec_registry = (
    EASI.codec_registry_builder()
    .with_default_codecs(True)
    .with_decoder_for_transfer_syntax("1.2.840.10008.1.2.4.90", Jpeg2000Decoder)
    .build()
)
Clone Existing Registry and Control Validation

Clone a base registry, add an encoder, and control assert-valid behavior at build-time.

codecRegistry := EASI.codecRegistryBuilder()
  .withBaseCodecRegistry(existingRegistry, true)
  .withEncoder("png", pngEncoder)
  .withValidation({ requireDefaultDecoder: true })
  .withAssertValid(true)
  .build()
const codecRegistry = EASI.codecRegistryBuilder()
  .withBaseCodecRegistry(existingRegistry, true)
  .withEncoder("png", pngEncoder)
  .withValidation({ requireDefaultDecoder: true })
  .withAssertValid(true)
  .build();
var codecRegistry = EASI.CodecRegistryBuilder()
    .WithBaseCodecRegistry(existingRegistry, true)
    .WithEncoder("png", pngEncoder)
    .WithValidation(new { requireDefaultDecoder = true })
    .WithAssertValid(true)
    .Build();
var codecRegistry = EASI.codecRegistryBuilder()
    .withBaseCodecRegistry(existingRegistry, true)
    .withEncoder("png", pngEncoder)
    .withValidation(Map.of("requireDefaultDecoder", true))
    .withAssertValid(true)
    .build();
codec_registry = (
    EASI.codec_registry_builder()
    .with_base_codec_registry(existing_registry, True)
    .with_encoder("png", png_encoder)
    .with_validation({"requireDefaultDecoder": True})
    .with_assert_valid(True)
    .build()
)
