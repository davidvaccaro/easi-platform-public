AttributeSet

Represents a searchable collection of attributes keyed by tag identity.

Type Snapshot

Field Value
Type AttributeSet
Domain Core
Category Container
Kind Instance Type

Canonical Role

Base attribute container for data-set, meta-set, and item scopes.

Pipeline Exposure

Materialized or traversed as part of streaming parse outputs and terminal products.

Type Definition

Structure is presented first, followed by language-neutral and language-specific examples, and an explicit UML relationship view.

Language-Neutral Examples

Basic usage:

pipeline := EASI.pipelineBuilder()
  .fromPartStream()
  .ofDicomData()
  .toInstances()
  .build()

resultCollection := pipeline.process(source)
result := resultCollection.first()

# Type usage
attributeSet := result.dataSet

Real-world usage: extract operational metadata for downstream workflow decisions.

ingestResultCollection := ingestPipeline.process(source)
ingestResult := ingestResultCollection.first()
attributeSet := ingestResult.dataSet
studyInstanceUid := attributeSet.value(Tag.StudyInstanceUID)
modalityCode := attributeSet.value(Tag.Modality)
