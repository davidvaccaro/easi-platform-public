TagSet

Represents a collection of tags for policy-driven selection and filtering.

Type Snapshot

Field Value
Type TagSet
Domain Core
Category Container
Kind Instance Type

Canonical Role

Lightweight tag profile container used in selection and masking paths.

Pipeline Exposure

Materialized or traversed as part of streaming parse outputs and terminal products.

Type Definition

Structure is presented first, followed by language-neutral and language-specific examples, and an explicit UML relationship view.

Language-Neutral Examples

Basic usage:

pipeline := EASI.pipelineBuilder()
  .fromPartStream()
  .ofDicomData()
  .toInstances()
  .build()

resultCollection := pipeline.process(source)
result := resultCollection.first()

# Type usage
tagSet := TagSet()
tagSet.add(Tag.PatientID)
tagSet.add(Tag.StudyInstanceUID)

Real-world usage: extract operational metadata for downstream workflow decisions.

tagSet := TagSet()
tagSet.add(Tag.PatientID)
tagSet.add(Tag.StudyInstanceUID)
containsStudyUid := tagSet.has(Tag.StudyInstanceUID)
