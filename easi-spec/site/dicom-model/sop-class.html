Language-Neutral Examples

Basic usage:

pipeline := EASI.pipelineBuilder()
  .fromPartStream()
  .ofDicomData()
  .toInstances()
  .build()

resultCollection := pipeline.process(source)
result := resultCollection.first()

# Type usage
sopClass := SOPClass.find("1.2.840.10008.5.1.4.1.1.2")

Real-world usage: dispatch processing by SOP Class UID.

sopClass := SOPClass.find("1.2.840.10008.5.1.4.1.1.2")
sopClassUid := sopClass.ID
sopClassName := sopClass.Name
