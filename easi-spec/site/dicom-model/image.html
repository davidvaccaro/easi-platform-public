Image

Extends entity access with image decode and frame-oriented behavior.

Type Snapshot

Field Value
Type Image
Domain Entities
Category Entity Accessor
Kind Entity Accessor Type

Canonical Role

Primary image-centric accessor for pixel-aware workflows.

Pipeline Exposure

Materialized by entity-oriented outputs and traversed during higher-level semantic access.

Type Definition

Structure is presented first, followed by language-neutral and language-specific examples, and an explicit UML relationship view.

Methods
decodeFrame(destination, decoder = null, frame = 0, windowCenter = null, windowWidth = null)

Decode the pixel data to the destination Uint8Array.

Parameters

Name Type Description
destination ByteArray The destination ByteArray that serves as the destination of the decode operation.
decoder Object (Optional) The desired decoder. Defaults to RGBA.
frame Number (Optional) The frame index (for multi-frame images) to decode. Defaults to 0.
windowCenter Any (Optional) Parameter used by this member.
windowWidth Any (Optional) Parameter used by this member.

Language-Neutral Examples

Basic usage:

pipeline := EASI.pipelineBuilder()
  .fromPartStream()
  .ofDicomData()
  .toEntities()
  .build()

resultCollection := pipeline.process({ source: source })
result := resultCollection.first()

# Type usage
image := result

Real-world usage: pull frame geometry for rendering/decode planning.

ingestResultCollection := ingestPipeline.process({ source: source })
ingestResult := ingestResultCollection.first()
image := ingestResult
rows := image.imagePixelModule.rows
columns := image.imagePixelModule.columns
