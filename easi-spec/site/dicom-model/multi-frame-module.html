MultiFrameModule

Provides multi-frame metadata including frame count and stereo-pair indicators.

Type Snapshot

Field Value

Domain Modules
Category Module Accessor
Kind Module Accessor Type

Canonical Role

Supports frame-indexed decode and multi-frame processing flows.

Language-Neutral Examples

Basic usage:

pipeline := EASI.pipelineBuilder()
  .fromPartStream()
  .ofDicomData()
  .toInstances()
  .build()

resultCollection := pipeline.process({ source: source })
result := resultCollection.first()

# Type usage
multiFrameModule := MultiFrameModule(result.dataSet)

Real-world usage: access module-level metadata for routing and transformation.

ingestResultCollection := ingestPipeline.process({ source: source })
ingestResult := ingestResultCollection.first()
multiFrameModule := MultiFrameModule(ingestResult.dataSet)
numberOfFrames := multiFrameModule.numberOfFrames
