Module

Base module accessor class with shared value and sequence helper methods.

Type Snapshot

Field Value

Domain Modules
Category Module Base

Canonical Role

Foundation for all domain-specific module accessors.

Pipeline Exposure

Constructed as focused access layer over attribute sets for module-scoped semantics.

Language-Neutral Examples

Basic usage:

pipeline := EASI.pipelineBuilder()
  .fromPartStream()
  .ofDicomData()
  .toInstances()
  .build()

resultCollection := pipeline.process(source)
result := resultCollection.first()

# Type usage
module := Module(result.dataSet)

Real-world usage: access module-level metadata for routing and transformation.

ingestResultCollection := ingestPipeline.process(source)
ingestResult := ingestResultCollection.first()
module := Module(ingestResult.dataSet)
seriesItems := module.accessSequenceItems(Tag.ReferencedSeriesSequence)
