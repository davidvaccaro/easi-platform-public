EncapsulatedDocument

Entity accessor for encapsulated document objects and payload metadata.

Canonical Role

Language-Neutral Examples

Basic usage:

pipeline := EASI.pipelineBuilder()
  .fromPartStream()
  .ofDicomData()
  .toEntities()
  .build()

resultCollection := pipeline.process({ source: source })
result := resultCollection.first()

# Type usage
wrappedEntity := EncapsulatedDocument.wrap({ mimeType: "application/pdf", bytes: payloadBytes })
wrappedEntity.unwrap()
EncapsulatedDocument.unwrap(wrappedEntity)

Real-world usage: project instance content into higher-level entity semantics.

wrappedEntity := EncapsulatedDocument.wrap({ mimeType: "application/pdf", bytes: payloadBytes })
wrappedEntity.unwrap()
EncapsulatedDocument.unwrap(wrappedEntity)
unwrappedViaInstance := wrappedEntity.unwrap()
unwrappedViaStatic := EncapsulatedDocument.unwrap(wrappedEntity)
wrappedFromDescriptor := EncapsulatedDocument.wrap({ mimeType: "application/pdf", bytes: payloadBytes })
mimeType := unwrappedViaStatic.mimeType
documentLength := unwrappedViaStatic.byteLength
