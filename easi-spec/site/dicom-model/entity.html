Entity

Provides high-level object accessors over instance or attribute-set content.

Type Snapshot

Field Value
Type Entity
Domain Entities
Category Entity Accessor
Kind Entity Accessor Type

Canonical Role

Base accessor used for entity-style pipeline output projections.

Pipeline Exposure

Materialized by entity-oriented outputs and traversed during higher-level semantic access.

Structure is presented first, followed by language-neutral and language-specific examples, and an explicit UML relationship view.

Language-Neutral Examples

Basic usage:

pipeline := EASI.pipelineBuilder()
  .fromPartStream()
  .ofDicomData()
  .toEntities()
  .build()

resultCollection := pipeline.process(source)
result := resultCollection.first()

# Type usage
entity := result

Real-world usage: project instance content into higher-level entity semantics.

ingestResultCollection := ingestPipeline.process(source)
ingestResult := ingestResultCollection.first()
entity := ingestResult
sopClassUid := entity.sopClassUid
seriesUid := entity.generalSeriesModule.seriesInstanceUid
