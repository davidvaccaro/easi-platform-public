Item

Represents one sequence-item scope containing its own attribute collection.

Type Snapshot

Field Value
Type Item
Domain Core
Category Container
Kind Instance Type

Canonical Role

Maintains nested sequence item boundaries and scope-local attributes.

Pipeline Exposure

Materialized or traversed as part of streaming parse outputs and terminal products.

Structure is presented first, followed by language-neutral and language-specific examples, and an explicit UML relationship view.

Language-Neutral Examples

Basic usage:

pipeline := EASI.pipelineBuilder()
  .fromPartStream()
  .ofDicomData()
  .toInstances()
  .build()

resultCollection := pipeline.process({ source: source })
result := resultCollection.first()

# Type usage
sequence := result.dataSet.find(Tag.ReferencedSeriesSequence)
item := sequence.items[0]

Real-world usage: extract operational metadata for downstream workflow decisions.

ingestResultCollection := ingestPipeline.process({ source: source })
ingestResult := ingestResultCollection.first()
sequence := ingestResult.dataSet.find(Tag.ReferencedSeriesSequence)
item := sequence.items[0]
referencedSopInstanceUid := item.value(Tag.ReferencedSOPInstanceUID)
