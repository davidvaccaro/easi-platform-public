PatientModule

Provides patient-demographic accessors over an attribute-set context.

Type Snapshot

Field Value

Domain Modules
Category Module Accessor
Kind Module Accessor Type

Canonical Role

Used by entity-level accessors for patient identity projections.

Pipeline Exposure

Constructed as focused access layer over attribute sets for module-scoped semantics.

Language-Neutral Examples

Basic usage:

pipeline := EASI.pipelineBuilder()
  .fromPartStream()
  .ofDicomData()
  .toInstances()
  .build()

resultCollection := pipeline.process(source)
result := resultCollection.first()

# Type usage
patientModule := PatientModule(result.dataSet)

Real-world usage: access module-level metadata for routing and transformation.

ingestResultCollection := ingestPipeline.process(source)
ingestResult := ingestResultCollection.first()
patientModule := PatientModule(ingestResult.dataSet)
patientId := patientModule.patientId
patientName := patientModule.patientName
