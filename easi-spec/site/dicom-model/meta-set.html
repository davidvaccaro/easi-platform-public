MetaSet

Represents File Meta Information attributes for framing and encoding context.

Type Snapshot

Field Value
Type MetaSet
Domain Core
Category Container
Kind Instance Type

Canonical Role

Carries transfer and identity metadata for compatibility-sensitive behavior.

Pipeline Exposure

Materialized or traversed as part of streaming parse outputs and terminal products.

Language-Neutral Examples

Basic usage:

pipeline := EASI.pipelineBuilder()
  .fromPartStream()
  .ofDicomData()
  .toInstances()
  .build()

resultCollection := pipeline.process(source)
result := resultCollection.first()

# Type usage
metaSet := result.metaSet

Real-world usage: extract operational metadata for downstream workflow decisions.

ingestResultCollection := ingestPipeline.process(source)
ingestResult := ingestResultCollection.first()
metaSet := ingestResult.metaSet
transferSyntaxUid := metaSet.transferSyntaxUID.ID
mediaStorageSopClassUid := metaSet.mediaStorageSOPClassUID.ID
