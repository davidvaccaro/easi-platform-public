Instance

Represents one full Part-10 object including preamble, prefix, meta-set, and data-set.

Type Snapshot

Field Value
Type Instance
Domain Core
Category Top-Level Object
Kind Instance Type

Canonical Role

Canonical object returned by many toInstances workflows.

Pipeline Exposure

Materialized or traversed as part of streaming parse outputs and terminal products.

Language-Neutral Examples

Basic usage:

pipeline := EASI.pipelineBuilder()
  .fromPartStream()
  .ofDicomData()
  .toInstances()
  .build()

resultCollection := pipeline.process(source)
result := resultCollection.first()

# Type usage
instance := result

Real-world usage: extract operational metadata for downstream workflow decisions.

ingestResultCollection := ingestPipeline.process(source)
ingestResult := ingestResultCollection.first()
instance := ingestResult
studyInstanceUid := instance.dataSet.value(Tag.StudyInstanceUID)
sopInstanceUid := instance.dataSet.value(Tag.SOPInstanceUID)
