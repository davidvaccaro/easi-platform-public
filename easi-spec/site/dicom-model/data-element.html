DataElement

Represents one encoded data element with value-length and completion state.

Type Snapshot

Field Value
Type DataElement
Domain Core
Category Encoding
Kind Instance Type

Canonical Role

Base encoded element abstraction extended by specific model elements.

Pipeline Exposure

Materialized or traversed as part of streaming parse outputs and terminal products.

Type Definition

Structure is presented first, followed by language-neutral and language-specific examples, and an explicit UML relationship view.

Type Structure

Directly available members for DataElement, separated by accessors/properties, methods, and constructors.

Accessors and Properties
Member Signature Kind Description
isComplete get isComplete() Accessor Determine if the current data element has ALL data present.
isComplete set isComplete(complete) Mutator Sets the complete state and thereby overrides the default length comparison approach.
bytesRemaining get bytesRemaining() Accessor Determine the bytes remaining to complete this data element.
valueLength valueLength Property Represents value length.
complete complete Property Represents complete.

Language-Neutral Examples

Basic usage:

pipeline := EASI.pipelineBuilder()
  .fromPartStream()
  .ofDicomData()
  .toInstances()
  .build()

resultCollection := pipeline.process({ source: source })
result := resultCollection.first()

# Type usage
dataElement := DataElement(result.dataSet.find(Tag.PatientName).access(), result.metaSet.transferSyntax, 0)

Real-world usage: extract operational metadata for downstream workflow decisions.

ingestResultCollection := ingestPipeline.process({ source: source })
ingestResult := ingestResultCollection.first()
dataElement := DataElement(ingestResult.dataSet.find(Tag.PatientName).access(), ingestResult.metaSet.transferSyntax, 0)
bytesRemaining := dataElement.bytesRemaining
isComplete := dataElement.isComplete
