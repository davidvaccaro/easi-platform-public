EncodedData

Wraps raw bytes with transfer-syntax awareness and endian-safe operations.

Type Snapshot

Field Value
Type EncodedData
Domain Core
Category Encoding
Kind Instance Type

Canonical Role

Shared encoded buffer abstraction across element-level model classes.

Pipeline Exposure

Materialized or traversed as part of streaming parse outputs and terminal products.

Language-Neutral Examples

Basic usage:

pipeline := EASI.pipelineBuilder()
  .fromPartStream()
  .ofDicomData()
  .toInstances()
  .build()

resultCollection := pipeline.process(source)
result := resultCollection.first()

# Type usage
encodedData := EncodedData(result.dataSet.find(Tag.PixelData).access(), result.metaSet.transferSyntax)

Real-world usage: extract operational metadata for downstream workflow decisions.

ingestResultCollection := ingestPipeline.process(source)
ingestResult := ingestResultCollection.first()
encodedData := EncodedData(ingestResult.dataSet.find(Tag.PixelData).access(), ingestResult.metaSet.transferSyntax)
encodedData.convert(TransferSyntax.ExplicitVRLittleEndian)
encodedLength := encodedData.length()
