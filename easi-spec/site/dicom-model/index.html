DICOM® Type Index

Primary type reference for EASI DICOM® composition, organized across core model types, entity accessors, and module accessors.

Each type page follows the same format: structure, language-neutral and language-specific examples, then UML relationships. For a complete system view, open the DICOM® type diagram.

Core

Type Category Kind Summary
Attribute Core Element Instance Type Represents one decoded DICOM® attribute with tag and VR-aware value semantics.
AttributeSequence Container Instance Type Represents a sequence attribute containing nested item collections.
AttributeSet Container Instance Type Represents a searchable collection of attributes keyed by tag identity.
DataElement Encoding Instance Type Represents one encoded data element with value-length and completion state.
DataSet Container Instance Type Represents the primary clinical attribute payload for one instance.
EncodedData Encoding Instance Type Wraps raw bytes with transfer-syntax awareness and endian-safe operations.
Instance Top-Level Object Instance Type Represents one full Part-10 object including preamble, prefix, meta-set, and data-set.
Item Container Instance Type Represents one sequence-item scope containing its own attribute collection.
MetaSet Container Instance Type Represents File Meta Information attributes for framing and encoding context.
Modality Vocabulary Static Type Provides modality code definitions and lookup by well-known identifiers.
PixelData Pixel Payload Instance Type Parses encapsulated pixel payload structures including offset tables and frame items.
Preamble Part-10 Envelope Instance Type Represents the 128-byte Part-10 preamble field.
Prefix Part-10 Envelope Instance Type Represents the 4-byte DICM prefix field in Part-10 files.
SOPClass Vocabulary Static Type Provides SOP Class UID definitions and lookup behavior.
Tag Vocabulary Static Registry + Instance Type Represents tag identifiers and dictionary-backed lookup helpers.
TagSet Container Instance Type Represents a collection of tags for policy-driven selection and filtering.
TransferSyntax Vocabulary Static Type Provides transfer syntax UID definitions and encoding capability metadata.
UnwrappedDocument Core Model Instance Type Unwrapped Document type reference for EASI DICOM® processing.
ValueRepresentation Vocabulary Static Type Provides VR definitions to interpret attribute value typing and length rules.
