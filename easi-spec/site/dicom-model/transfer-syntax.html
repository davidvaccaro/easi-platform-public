Language-Neutral Examples

Basic usage:

pipeline := EASI.pipelineBuilder()
  .fromPartStream()
  .ofDicomData()
  .toInstances()
  .build()

resultCollection := pipeline.process({ source: source })
result := resultCollection.first()

# Type usage
transferSyntax := TransferSyntax.find("1.2.840.10008.1.2.1")

Real-world usage: choose decode/transcode policy.

transferSyntax := TransferSyntax.find("1.2.840.10008.1.2.1")
isCompressed := transferSyntax.IsCompressed
isLittleEndian := transferSyntax.IsLittleEndian
