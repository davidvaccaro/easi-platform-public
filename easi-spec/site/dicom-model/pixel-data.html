PixelData

Parses encapsulated pixel payload structures including offset tables and frame items.

Type Snapshot

Field Value
Type PixelData
Domain Core
Category Pixel Payload
Kind Instance Type

Canonical Role

Bridges raw pixel attributes and frame-level decode or transcode flows.

Pipeline Exposure

Materialized or traversed as part of streaming parse outputs and terminal products.

Language-Neutral Examples

Basic usage:

pipeline := EASI.pipelineBuilder()
  .fromPartStream()
  .ofDicomData()
  .toInstances()
  .build()

resultCollection := pipeline.process(source)
result := resultCollection.first()

# Type usage
pixelData := PixelData(result.dataSet.find(Tag.PixelData))

Real-world usage: determine frame boundaries before decode.

ingestResultCollection := ingestPipeline.process(source)
ingestResult := ingestResultCollection.first()
pixelData := PixelData(ingestResult.dataSet.find(Tag.PixelData))
frameCount := pixelData.offsets.length
