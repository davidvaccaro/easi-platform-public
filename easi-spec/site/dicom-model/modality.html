Language-Neutral Examples

Basic usage:

pipeline := EASI.pipelineBuilder()
  .fromPartStream()
  .ofDicomData()
  .toInstances()
  .build()

resultCollection := pipeline.process(source)
result := resultCollection.first()

# Type usage
modality := Modality.find("CT")

Real-world usage: route workflows by modality capabilities.

modality := Modality.find("CT")
modalityCode := modality.ID
isMultiFrame := modality.IsMultiFrame
