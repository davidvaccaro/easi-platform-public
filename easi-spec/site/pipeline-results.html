Pipeline Result Contract

EASI uses one unified result contract so callers always handle pipeline outputs consistently. The contract has two layers: PipelineResultCollection (outer container) and PipelineOperationResult (standardized operation envelope when applicable).

Normative Intent

process(...) and per-transaction start(...) callbacks return PipelineResultCollection. This provides stable cardinality handling independent of terminal shape. When terminal or writer operations expose operation metadata, the item value may be a PipelineOperationResult envelope.

PipelineResultCollection

This is the universal top-level return type for pipeline transactions. It gives callers one predictable way to check for output and access the first (or only) item.

Surface Purpose Typical Use
isEmpty / count Cardinality checks before reading output. Fail fast if no result was produced.
first() Direct access to first (or only) item. Most common call-site pattern.
at(...), last() Indexed access for multi-item transactions. Work with plural outputs when needed.
toArray(), iteration helpers Collection traversal utilities. Batch processing, filtering, projection.

PipelineOperationResult

This is a standardized operation envelope for terminal/writer outcomes when operation metadata is relevant. It allows callers to evaluate write/materialization outcomes without relying on destination-specific custom fields.

Field Type Meaning
resultType String Stable discriminator ("PipelineOperationResult").
version String Envelope contract version.
operation String Operation identity (for example terminal operation name or "into").
category String Operation class (for example "terminal" or "writer").
bytesWritten Integer Standardized byte count for write/emit outcomes.
materialized Boolean Whether a payload was materialized on the result.
payload ByteArray or Null Materialized payload bytes when present.
output Any Raw terminal/writer output object captured by the envelope.
writer (Optional) String Writer type identity when emitted by writer-category results.

How They Work Together

resultCollection := pipeline.process(...)
if resultCollection.isEmpty:
  fail("No result")

item := resultCollection.first()
if item.resultType == "PipelineOperationResult":
  evaluate(item.bytesWritten, item.materialized)
else:
  consume domain output directly

The caller always starts with the collection contract; operation envelopes are detected only when needed.

Usage

Transactional and Listener Patterns

results := pipeline.process(source, destination)
if results.isEmpty:
  fail("Expected result")

item := results.first()
if item.resultType == "PipelineOperationResult":
  if item.bytesWritten <= 0:
    fail("No output bytes")

run := listenerPipeline.start({
  onResult: (resultCollection, context) => {
    if resultCollection.isEmpty:
      return true
    first := resultCollection.first()
    // first may be a domain object or a PipelineOperationResult
    return true
  }
})

JavaScript Pattern

const results = await pipeline.process(source, destination);
if (results.isEmpty) {
  throw new Error("Expected result.");
}

const item = results.first();
if (item?.resultType === "PipelineOperationResult") {
  if ((item.bytesWritten ?? 0) <= 0) {
    throw new Error("No output bytes.");
  }
}

const run = await listenerPipeline.start({
  onResult: async (resultCollection, context) => {
    if (resultCollection.isEmpty) {
      return true;
    }

    const first = resultCollection.first();
    // first may be a domain object or a PipelineOperationResult
    return true;
  }
});

C# Pattern

var results = await pipeline.Process(source, destination);
if (results.IsEmpty) {
    throw new InvalidOperationException("Expected result.");
}

var item = results.First();
if (item?.resultType == "PipelineOperationResult") {
    if ((item.bytesWritten ?? 0) <= 0) {
        throw new InvalidOperationException("No output bytes.");
    }
}

var run = await listenerPipeline.Start(new {
    onResult = (Func<dynamic, dynamic, bool>)((resultCollection, context) => {
        if (resultCollection.IsEmpty) {
            return true;
        }

        var first = resultCollection.First();
        // first may be a domain object or a PipelineOperationResult
        return true;
    })
});

Java Pattern

var results = pipeline.process(source, destination);
if (results.isEmpty()) {
    throw new RuntimeException("Expected result.");
}

var item = results.first();
if ((item != null) && "PipelineOperationResult".equals(item.resultType)) {
    if (((Number) item.bytesWritten).longValue() <= 0L) {
        throw new RuntimeException("No output bytes.");
    }
}

var run = listenerPipeline.start(Map.of(
    "onResult", (BiFunction<Object, Object, Boolean>) (resultCollection, context) -> {
        if (resultCollection.isEmpty()) {
            return true;
        }

        var first = resultCollection.first();
        // first may be a domain object or a PipelineOperationResult
        return true;
    }
));

Python Pattern

results = pipeline.process(source, destination)
if results.is_empty:
    raise RuntimeError("Expected result.")

item = results.first()
if getattr(item, "resultType", None) == "PipelineOperationResult":
    if int(getattr(item, "bytesWritten", 0)) <= 0:
        raise RuntimeError("No output bytes.")

run = listener_pipeline.start({
    "onResult": lambda result_collection, context: (
        True if result_collection.is_empty
        else True  # result_collection.first() may be domain output or PipelineOperationResult
    )
})
