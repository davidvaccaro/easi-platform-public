EASI - Technical Reference

EASI (Expressive API Standard for Imaging) defines a fluent, language-neutral domain specific language for DICOM® orchestration and stream processing.


The primary goals of this standard are:

  • Expressive composition
  • Emphasize efficient, event-driven, "in-flight" stream processing
  • Define a fluent, language-neutral DSL that is implementation-portable
  • Standardize staged pipeline semantics for predictable composition and execution
  • Provide deterministic stream lifecycle events and consistent result contracts
  • Support early-bound, late-bound, and hybrid binding models for reusable pipeline contracts
  • Maintain first-class interoperability across DIMSE, DICOMweb™ and bespoke workflows
  • Enable extension through mappings, selections, filters, and writers without weakening conformance
  • Improve AI agentic fluency through readable, constrained, intent-first pipeline definitions

This reference is the primary source for both language-neutral semantics and language-specific usage, with ample cross-language samples presented throughout.

Normative Focus

A topic belongs in this standard when independent implementations must behave the same way to remain interoperable. Internal class structures, runtime utilities, and language-specific ergonomics remain language-specific implementation details.
