EASI Standard Technical Reference

EASI (Expressive API Standard for Imaging) defines a fluent, language-neutral contract for the efficient stream processing of DICOM® medical information.


This site is the primary source for both language-neutral semantics and language-specific usage, with ample cross-lanuguage samples presented throughout.

Normative Focus

A topic belongs in this standard when independent implementations must behave the same way to remain interoperable. Internal class structures, runtime utilities, and language-specific ergonomics remain language-specific implementation details.

Reference Index

The following index organizes the EASI processing architecture, materialization scheme, result output models, error handling and advanced features all with language-neutral and language-specific examples and real-world DICOM® use-cases.
