Profile Index

This page provides an EASI-oriented index of DICOM® entities, modules, and high-value element references used by common read, selection, mapping, and transfer workflows.

Scope Note

This is not a restatement of the full DICOM® standard. It is a focused interoperability index used to anchor EASI scenario and mapping behavior against commonly required attributes.

DICOM® Data Model Type Catalog

For resource-style type references, use the dedicated data model index and per-type pages. This catalog covers core model classes plus document utilities, entity accessors, and module accessors commonly emitted or traversed during pipeline processing.

DICOM® Model Type Index

Includes dedicated references for Instance, DataSet, Attribute, Tag, TransferSyntax, and other root model classes.

Reference Style

Each class page includes snapshot metadata, canonical role, common relationships, and typical output contexts across pipeline terminals, with language-neutral and language-specific tabs.

EASI Mapping Notes

ImagingStudy Mapping

Study/series/instance UIDs are the minimum stable identity set for reducing duplicate projections.

Selection Profiles

Selection-first workflows should prioritize UID attributes and safety-critical demographics before optional descriptors.

De-Identification
