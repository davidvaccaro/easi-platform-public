# easi-cs

Reserved for the future C# implementation of the EASI API within the BrightDicom monorepo.

Planned high-level layout:

- `src/` C# runtime/library implementation (`EASI` API surface)
- `test/` unit/integration tests
- `doc/` implementation notes and language-specific documentation

The previous DICOM code-generation tooling that lived here has been moved out of this repo.
