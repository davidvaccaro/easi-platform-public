# EASI UI Roadmap

## Phase 0: Scaffold

- Workspace structure
- Package boundaries
- Placeholder exports

## Phase 1: Core Primitives

- Typography, spacing, color tokens
- Panel, card, table, tabs, form controls

## Phase 2: Imaging Domain Widgets

- DICOM tag tree/table viewer
- FHIR JSON viewer
- Basic image viewport
- Pipeline status timeline

## Phase 3: Adapter Expansion

- React wrappers
- Angular wrappers
- Vue wrappers

## Phase 4: Studio Integration

- Reuse components in EASI Composition Studio
- Stabilize API contracts for UI package consumers
